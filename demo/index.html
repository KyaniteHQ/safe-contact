safe-contact

Show your email to people, not to spam bots.

Bots scrape pages for addresses and sell them to spammers. safe-contact keeps the address out of your page until a person points at it, focuses it or taps it. It looks and works like a normal link.

In Next.js and other server-component apps, the address is scrambled on the server and never reaches the browser. Nothing to set up.

Any website

npx safe-contact you@yoursite.com

Paste the HTML it prints, and add this once per page:

<script src="https://unpkg.com/safe-contact/dist/auto.js" defer></script>

How it works

  1. The page holds a decoy in place of the address: a made-up user name, domain and top-level domain that reads like an address but cannot be delivered. For a phone number it is random digits after +0, a country code that does not exist. A bot that harvests the page gets junk.
  2. The real link is kept scrambled in a data-safe-contact attribute. Its href is just #: no mailto: link for a bot to follow, but it looks and behaves like any other link.
  3. When someone hovers, focuses, taps or clicks, the decoy becomes the real address and the link a real one, just before the click lands. One click opens the mail app.

Screen readers hear “Email address, activate to show” until the link is focused. The browser script is under 1 KB and needs no CSS.

No trick stops a bot that is built to beat it. Most harvesters just read the HTML, some run the page in a browser, and very few hover over links. This stops all but the last kind.
